## 一、技术栈总览

| 项目 | 技术选型 | 说明 |
|------|---------|------|
| 原生框架 | Android Native (Java/Kotlin) | 主壳、路由、生命周期管理 |
| 混合渲染 | **Flexo 自研动态渲染框架** | 类似 RN/Flutter 的跨端方案，通过 `bootstrap.txt` 加载模板，`NativeElements` 调用原生组件 |
| H5 容器 | WebView + Native Bridge | 通过 `action:` 协议桥接原生与 H5 |

| 动画渲染 | Lottie + PAG | `circle_diffusion.json`（Lottie）、`head_company_domi.pag`（PAG） |

### 3.2 Flexo 动态渲染框架

Flexo 是涨乐的自研跨端渲染框架，核心机制：

```javascript
// bootstrap.txt 中的核心 API
__DataSource__    // 数据源管理，通过 flexo.request() 异步请求数据
__Reference__     // 组件引用，支持 show()/hide() 控制显隐
__Component__     // 基础组件类，包含生命周期：
                  //   onCreate / onMount / onUnmount
                  //   onShow / onHide / onReuse
__extends__       // 继承机制，类似 React 的 class component
NativeElements    // 原生组件桥接，直接调用平台渲染
```

**组件属性体系：**

| 属性 | 类型 | 说明 |
|------|------|------|
| `state` | Object | 组件状态（类似 React state） |
| `native` | Object | 原生配置 |
| `dataSourceMap` | Object | 数据源映射表 |
| `templateId` | String | 模板 ID |
| `templateVersion` | String | 模板版本号（默认 `-1`） |
| `instanceId` | Number | 实例 ID |
| `bizId` | String | 业务 ID |

**生命周期：**

```
onCreate → onMount → onShow ⇄ onHide → onUnmount
                        ↑
                    onReuse（复用）
```

### 9.1 架构模式：Native + 动态渲染 + H5 三层

```

  - 启动引导、权限管理、推送注册

  - 通过 JSON 模板 + JS 运行时动态渲染
  - 支持热更新，无需发版

Layer 3: WebView H5 容器
  - 活动、资讯、帮助等低频页面
  - 通过 action: 协议桥接原生能力

### 9.2 通信协议设计要点

1. **多链路分离**：开户、行情、交易、资讯、聊天、认证各自独立链路，互不影响
2. **DNS 动态解析**：`isEnableDns=1`，优先域名、备选 IP，支持灰度切换
3. **协议版本化**：`protocol: 2013`（主协议）、`ual`（认证协议），独立演进
4. **TLS 分级**：仅认证链路启用 TLS，业务链路走自定义加密（性能优化）
5. **旁路推送**：交易链路有 `sidePort` 旁路端口，用于行情/成交通知

### 10.1 产品定位

"早点听"取代了传统券商 App 所有零散的资讯入口，成为用户启动 App 后的**默认首页**。定位为"晨间决策官"，核心理念是**信息减熵**——将无序的海量数据转化为有序的个性化洞察。

**核心价值主张：**
- 一次播报抵过十次刷屏

### 10.3 三时段播报体系

#### 盘前播报（8:00 左右）

每日早上自动生成 8-10 分钟 AI 音频播报，核心内容：

| 模块 | 内容 | 说明 |
|------|------|------|
| 大盘整体走势 | A股三大指数、隔夜美股、全球市场概览 | 宏观环境快速扫描 |
| 板块热点 | 当日热门板块、资金净流入板块 | AI 自动识别热点轮动 |
| 持仓/自选股异动 | 与用户持仓和自选股强相关的重大事件 | **个性化过滤**，只播报用户关心的 |
| 涨停猎手 | 基于资金流向筛选的潜在强势标的 | 专为短线投资者 |
| 事件捕手 | 影响企业中长期经营的底层变量 | 专为中长线投资者 |
| 公告提炼 | 持仓股发布的业绩预告/重大公告 AI 提炼核心要点 | 把几十页报告变成几句话 |

**播报特点：**
- 音频形式，通勤路上可听
- AI 用"人话"解读，不说废话
- 个性化：只播报与你持仓、自选股相关的内容
- 例：持仓股发布业绩预告 → AI 提炼核心要点，告诉你数据变化和背后原因

#### 盘中播报（交易时段）

| 模块 | 内容 | 说明 |
|------|------|------|
| 持仓异动提醒 | 自选股/持仓股价格、资金异动 | 便签式提醒，附 AI 简短分析 |
| 重大事件推送 | 影响持仓的重大新闻/公告 | 实时追踪 |
| 资金流向 | 主力资金进出实时监控 | 与涨停猎手联动 |
| 语音提醒 | 重要异动和消息语音及时提醒 | 不需盯屏 |

**盘中播报设计哲学：**
- 与传统工具持续推送所有市场热点不同，AI 涨乐**提前进行信息过滤**
- 只关注与用户直接相关的持仓变动和市场信息
- 避免无关噪音干扰投资者决策过程

#### 盘后播报（收盘后）

| 模块 | 内容 | 说明 |
|------|------|------|
| 当日复盘 | 涨跌统计、资金流向、板块轮动 | 全天回顾 |
| 持仓日报 | 用户持仓当日盈亏、异动汇总 | 个性化持仓报告 |
| 明日关注 | 次日重要事件、数据预告 | 提前准备 |
| 策略回顾 | 用户设置的条件单/网格策略执行情况 | 交易闭环 |

### 10.4 涨停猎手（短线智能体）

**定位：** 专为短线/打板投资者打造，聚焦资金流向，寻找短期强势标的。

| 能力 | 技术实现 | 用户价值 |
|------|---------|---------|
| 主力资金追踪 | 实时追踪主力资金流向，扫描全市场资金动向 | 帮用户轻松跟上主力、避免盲目追逐 |
| 量价行为建模 | 封板强度、换手率、成交量变化、主力资金流入等多维建模 | 识别封单更稳、资金更强的标的 |
| 多目标优化排序 | AI 情绪分析 + 量价行为 + 多因子排序 | 识别更可能走出二连、三连的龙头股 |
| 资金可视化 | 将资金持续流入的潜力板块/赛道可视化 | 直观看懂主力动向 |
| 持仓资金分析 | 对持仓/自选股中每只股票深度资金分析 | 识别主力是在悄悄进场还是暗中撤退 |
| 联动交易 | 后续盯盘 + 挂单 + 条件单联动 | 从发现到执行一站式完成 |
| 算法识别标注 | 自动标注异动类型 | 一目了然 |

**底层技术架构：**
```
涨停猎手
├── 数据层: Level-2 行情数据 + 逐笔成交 + 大单追踪
├── 模型层: 量价行为建模 + AI 情绪分析 + 多目标优化算法
├── 因子层: XGBoost + Transformer + MMOE 等架构，数百个因子排序
└── 输出层: 强势标的列表 + 资金流向可视化 + 联动盯盘/交易
```

### 10.5 事件捕手（中长线智能体）

**定位：** 深挖影响企业中长期经营的底层变量，服务于中长线布局。

| 能力 | 技术实现 | 用户价值 |
|------|---------|---------|
| 全市场事件扫描 | 扫描新闻事件、舆情、公告 | 捕捉市场热议事件与驱动事件 |
| 事件选股 | 基于事件关联度筛选个股 | 从事件到标的的精准映射 |
| 热词云展示 | AI 提取热点关键词可视化 | 快速感知市场焦点 |
| 驱动事件呈现 | 识别并呈现热点主题的驱动事件 | 理解事件背后的逻辑 |
| 关联个股筛选 | 事件与个股的关联映射 | 找到事件受益标的 |
| 事件传导链路可视化 | **行业首创**，因果链梳理与量化 | 看清事件对股价的传导路径 |
| 盯盘提醒联动 | 将特定事件设为前置盯盘条件 | 事件发现 → 分析 → 盯盘联动 |
| 历史回溯 | 标注类似历史事件在股价对应时间点的涨跌 | 以史为鉴 |

**事件传导链路可视化（核心创新）：**
```
事件发现 → 5-4-3-2-1 分制重要性评分
         → 定性+定量测算底层变量对企业中长期经营的传导逻辑
         → 可视化因果图谱呈现
         → 支持设为盯盘条件
         → 历史同类事件回溯对比
```

**底层技术架构：**
```
事件捕手
├── 数据层: 全网新闻 + 公告 + 舆情 + 财务数据
├── 模型层: LLM 事件识别 + 大模型因果推理 + 事件重要性评分
├── 风控层: 动态风险防控中枢（业绩变脸、监管问询等风险事件实时监控）
└── 输出层: 事件列表 + 传导链路可视化 + 关联个股 + 盯盘联动
```

### 10.6 重磅事件跟踪

**定位：** 聚焦影响市场中长期走势的宏观级、政策级重大事件，服务于中长线投资者的战略决策。

"重磅事件跟踪"是早点听工作区内的第三个核心板块，与"涨停猎手"（短线资金面）和"事件捕手"（个股级事件）形成互补，覆盖更高维度的重大事件。

| 能力 | 技术实现 | 用户价值 |
|------|---------|---------|
| 宏观级事件追踪 | AI 自动识别国家级政策、重大经济数据、国际地缘事件等 | 把握影响整个市场走向的系统性机会与风险 |
| 政策解读与传导 | 将重大政策拆解为行业影响链路，如"统一大市场→物流→兰剑智能" | 理解政策红利的行业传导路径，提前布局 |
| 重大事件推送 | 在早点听早报/晚报中优先推送重磅事件 | 确保不遗漏影响市场格局的关键信号 |
| 事件与持仓关联 | 自动判断重磅事件是否影响用户持仓股的经营基本面 | 从宏观到微观，评估事件对个人持仓的实质影响 |
| 历史事件回溯 | 标注类似重大历史事件在市场/板块对应时间点的表现 | 以史为鉴，辅助判断事件后续走势概率 |

**与事件捕手的区别：**

| 维度 | 事件捕手 | 重磅事件跟踪 |
|------|---------|------------|
| 事件层级 | 个股级（业绩预告、公告、行业事件） | 宏观级（国家政策、重大经济数据、地缘事件） |
| 影响范围 | 单个公司或单一行业 | 跨行业、全市场 |
| 投资周期 | 中长期企业经营变量 | 中长期市场格局变量 |
| 典型场景 | "某家电海外扩张预计净利润弹性+3%" | "降准0.5%→银行/地产/券商传导链" |

**在早点听中的呈现方式：**
- 早报/晚报中设有"重磅事件"专区，优先展示 5 级评分中 4-5 分的重大事件
- 点击事件可查看完整传导链路可视化
- 支持一键设置事件盯盘，跟踪事件后续发展
- 提供专属早/晚报推送，确保关键信号不被淹没在日常资讯中

## 十一、特别提醒页面

> **特别提醒**是 AI 涨乐三大核心工作区之一，定位为"全天候智能哨兵"，是中长线投资者不可或缺的信号监控中枢。

### 11.1 页面定位

解决核心痛点：**没时间盯盘、信息太多抓不住重点、不知该盯什么**。投资者害怕错过关键异动，但又不堪重负。

特别提醒采用"便签式提醒"设计，从"发生了什么"→"为什么"→"怎么办"三层递进，几十秒即可完成判断。

### 11.2 核心功能

| 功能 | 说明 | 中长线价值 |
|------|------|-----------|
| **自选股异动提醒** | 自选股/持仓股价格异动、量比异动实时推送 | 中长线持仓监控核心，不错过关键变化 |
| **持仓异动陪伴** | 监控个股异动、重大公告及行业风险，引导进入 AI 对话分析 | 持仓股的基本面变化是中长线调仓依据 |
| **基本面突变提醒** | 业绩预告/预警、重大公告、监管问询等基本面事件触发预警 | 中长线最关注的信号——企业基本面变脸 |
| **资金面异常提醒** | 主力资金大幅流入/流出异常信号 | 判断主力是进场还是撤退，辅助中长线决策 |
| **关键价位触及** | 预设价位（支撑位/压力位/成本线）触及提醒 | 中长线纪律化交易的关键工具 |
| **盯盘条件触发** | 用户自定义盯盘条件触发时推送 | 个性化监控，如"跌破 20 日均线提醒" |
| **AI 简短分析** | 每条提醒附带 AI 解读，分析异动原因和应对建议 | 不只告知"发生了什么"，更分析"为什么"和"怎么办" |

### 11.3 自选股异动提醒（重点展开）

自选股异动提醒是特别提醒中与中长线投资最紧密的功能，也是连接"早点听"信息获取和"持仓管理"执行的关键桥梁：

```
自选股异动触发流程：

  市场异动发生
       │
       ▼
  AI 实时监控引擎（7×24 小时云端运行）
       │
       ├── 价格异动检测：5 分钟涨跌幅超阈值 / 量比异常
       ├── 资金异动检测：主力资金大额进出 / 持续流入流出
       ├── 基本面异动检测：业绩预告 / 重大公告 / 监管问询
       └── 事件异动检测：关联重大事件触发
       │
       ▼
  个性化过滤（仅推送与用户自选/持仓相关的信号）
       │
       ▼
  便签式提醒推送（弹窗 + 语音 + 锁屏卡片）
       │
       ├── 发生了什么：异动类型 + 幅度
       ├── 为什么：AI 简短分析异动原因
       └── 怎么办：辅助决策建议（如"建议关注 XX 支撑位"）
```

**推送渠道：**
- App 内弹窗提醒
- 语音播报提醒
- 锁屏卡片提醒
- 微信 Clawbot 消息推送（需绑定）

### 11.4 盯盘体系

特别提醒背后是一套完整的 AI 盯盘体系：

| 盯盘模式 | 说明 | 中长线适用度 |
|---------|------|------------|
| 一句话盯盘 | 自然语言输入，如"茅台跌破 1450 元后反弹 1% 提醒我" | ★★★★★ 零门槛设监控 |
| 盯主力动向 | 监控主力资金进出异动 | ★★★★ 判断主力意图 |
| 盯重大风险 | 监控业绩变脸、监管问询等风险事件 | ★★★★★ 中长线风控核心 |
| 盯公告大事 | 监控持仓股重大公告发布 | ★★★★★ 基本面跟踪关键 |
| 盯阶段趋势 | 监控趋势突破/破位信号 | ★★★ 中长线择时辅助 |
| 盯日内高低价 | 日内价格极值触发 | ★★ 偏短线 |
| 事件盯盘联动 | 将事件捕手/传导链中的事件直接设为盯盘条件 | ★★★★★ 事件→监控闭环 |

### 11.5 技术架构

```
特别提醒
├── 监控层: 7×24 小时云端智能监控引擎（断网仍可触发）

├── 推送层: 弹窗 + 语音 + 锁屏卡片 + 微信 Clawbot 多通道
├── 分析层: AI 毫秒级分析引擎，附异动原因解读和应对建议
└── 排序层: 智能排序，只推送高影响度信号，避免信息轰炸

## 十二、动态估值页面

> **动态估值**是 AI 涨乐中长线投资的核心工具，解决"这只股票到底是贵还是便宜"的根本问题。基于华泰研究所专业投研框架，是传统券商研报能力的 AI 产品化。

### 12.1 页面定位

传统估值方法的痛点：
- PE/PB 等静态指标容易失真，无法反映公司最新经营状况
- DCF 等复杂估值模型普通投资者望而却步
- 研报估值数据滞后（通常季度更新），无法反映最新变化

动态估值的解决方案：**日频更新 + 四维度框架 + 五档定位**，让普通投资者也能科学判断内在价值。

### 12.2 四维度估值框架

基于华泰研究所专业投研框架，从四个核心维度全面评估个股价值：

| 维度 | 评估内容 | 关键指标 | 中长线意义 |
|------|---------|---------|-----------|
| **成长空间** | 行业增长天花板 + 第二曲线潜力 | 行业增速、新业务占比、市场空间 | 判断企业能长多大 |
| **护城河** | 技术壁垒 / 研发实力 / 品牌溢价 | 研发费率、专利数、品牌溢价率 | 判断竞争优势持续性 |
| **竞争格局** | 行业集中度 + 市占率变化 | CR3/CR5、市占率变动 | 判断定价权和利润率 |
| **经营绩效** | 营收质量 / ROE / 负债率 | ROE、营收增速、资产负债率 | 判断管理层执行力 |

### 12.3 五档估值定位

动态估值将个股当前估值水平以直观的五档形式呈现：

```
  ┌─────────────────────────────────────────────────────┐
  │  严重低估    低估    合理    高估    严重高估        │
  │    ████      ████   ████   ████     ████            │
  │                      ▲                               │
  │                  当前位置                             │
  └─────────────────────────────────────────────────────┘
```

- 一眼看出个股当前处于"低估"还是"高估"区间
- 结合历史估值区间对比，展示当前估值在历史分位中的位置
- 日频更新，反映公司最新经营变化和市场环境

### 12.4 技术实现

```
动态估值
├── 数据层: 分析师一致预期 + 公司经营绩效核心指标
├── 模型层: 华泰投研框架四维度模型 + AI 估算未来三年盈利
├── 更新层: 日频更新（非传统研报的季度更新）
├── 输出层: 五档定位 + 历史区间对比 + 四维度详细评分
└── 合规层: 估值结果仅供参考，不构成投资建议
```

**核心差异：**
- 传统研报估值：季度更新、专业门槛高、数据滞后
- AI 涨乐动态估值：日频更新、可视化呈现、零门槛理解

## 十三、事件传导页面

> **事件传导**是 AI 涨乐行业首创的核心功能，也是最具差异化的中长线分析能力。它不仅告诉你"发生了什么"，更以可视化形式呈现"事件如何一步步影响企业利润"。

### 13.1 页面定位

传统资讯软件的痛点：只按日期罗列资讯，无法回答"这个事件到底对我持仓的股票影响有多大"。

事件传导的突破：**量化分析复杂事件对个股净利润的影响，以因果链可视化呈现传导路径**。

### 13.2 五级事件重要性评分

| 评分 | 含义 | 典型事件 |
|------|------|---------|
| 5 分 | 极其重大，可能改变行业格局 | 国家级产业政策、重大并购重组 |
| 4 分 | 重大，显著影响企业中长期经营 | 行业监管新规、核心产品获批 |
| 3 分 | 较重要，间接影响企业经营 | 行业数据发布、上下游动态 |
| 2 分 | 一般，短期情绪影响 | 分析师评级调整、短期舆情 |
| 1 分 | 轻微，影响有限 | 日常经营动态、常规公告 |

### 13.3 事件传导链路可视化

这是事件传导页面的核心交互，以因果图谱呈现事件影响的传导路径：

```
事件传导链示例："新能源补贴政策调整"

  新能源补贴退坡
       │
       ├──→ 补贴减少 → 整车成本上升 → 终端售价承压
       │                              │
       │                              ├──→ A车企: 净利润弹性 -5%
       │                              └──→ B车企: 净利润弹性 -2%（成本控制好）
       │
       └──→ 行业洗牌加速 → 龙头集中度提升
                               │
                               └──→ C龙头: 净利润弹性 +3%（市占率提升）
```

**交互设计：**
- 点击传导链中任意节点可展开详细分析
- 每个影响节点标注定量影响（如"净利润弹性+3%"）
- 支持一键设置事件盯盘，跟踪事件后续发展
- 标注历史上类似事件在股价对应时间点的涨跌表现

### 13.4 定量+定性分析

事件传导不是简单的信息聚合，而是提供**定性+定量**双重分析：

| 分析类型 | 内容 | 示例 |
|---------|------|------|
| 定性分析 | 事件对企业经营逻辑的影响方向和持续性 | "海外扩张将打开新市场空间，预计3年内贡献收入增量" |
| 定量分析 | 事件对个股净利润的弹性测算 | "某家电海外扩张预计净利润弹性+3%" |

### 13.5 历史事件回溯

标注类似历史事件在股价对应时间点的涨跌表现，帮助投资者"以史为鉴"：
- 展示历史上同类事件发生后，个股/板块在 5 日/20 日/60 日的涨跌统计
- 标注当时的市场环境差异，避免简单类比
- 回溯结果仅作参考，不构成投资建议

### 13.6 已覆盖行业

截至 2026 年，事件传导功能已在以下行业建立实践路径：

| 行业 | 传导链覆盖情况 |
|------|--------------|
| 家电 | 产业链上下游传导完整 |
| 汽车 | 新能源/传统双线传导 |
| 医药 | 创新药/集采政策传导 |
| 电新 | 新能源/储能政策传导 |

### 13.7 技术架构

```
事件传导
├── 数据层: 全网新闻 + 公告 + 舆情 + 财务数据 + 产业链知识图谱
├── 识别层: LLM 事件识别 + 5 级重要性评分
├── 传导层: 大模型因果推理 + 定性+定量测算传导逻辑
├── 可视化层: 因果图谱可视化呈现
├── 联动层: 一键事件盯盘 + 关联个股筛选
└── 回溯层: 历史同类事件匹配 + 涨跌统计
```

## 十四、持仓陪伴页面

> **持仓陪伴**是 AI 涨乐面向中长线投资者的"7×24 小时专属交易员"，核心价值是让投资者无需时刻盯盘，也能对持仓动态了如指掌。

### 14.1 页面定位

中长线投资者最大的痛点：**买了之后不知道什么时候该卖，持仓股出了大事自己还不知道**。持仓陪伴功能就是解决这个"买了就不管"的困境。

### 14.2 核心功能

| 功能 | 说明 | 中长线价值 |
|------|------|-----------|
| **持仓异动陪伴** | 监控个股异动、重大公告及行业风险，引导进入 AI 对话分析 | 不错过任何影响持仓的重大变化 |
| **风险触发盯盘** | 自选股触发风险信号时，自动引导用户设置盯盘 | 风险事件自动识别 → 主动提醒 → 行动引导 |
| **持仓资金分析** | 每只持仓股的主力资金深度分析 | 识别主力是在悄悄进场还是暗中撤退 |
| **基本面跟踪** | 持仓股业绩预告/公告 AI 提炼核心要点 | 把几十页报告变成几句关键判断 |
| **AI 解套工具** | 持仓亏损时，AI 给出回测数据、止盈设置及复盘卡片 | 被套后的理性应对方案 |

### 14.3 持仓异动陪伴流程

```
持仓股异动发生
     │
     ▼
  AI 主动识别异动类型
     │

     ├── 基本面异动：业绩预告/预警、重大公告
     ├── 行业风险：行业政策变化、上下游异动
     └── 事件异动：关联重大事件触发
     │
     ▼
  主动推送提醒（特别提醒渠道）
     │
     ▼
  引导进入 AI 对话分析
     │
     ├── AI 解读异动原因
     ├── 评估对持仓的影响程度
     └── 提供应对建议（加仓/减仓/观望/设置盯盘）
```

## 十五、交易复盘页面

> **交易复盘**是中长线投资者建立系统化交易体系的关键工具，帮助从"盲目交易"走向"系统化交易"。

### 15.1 页面定位

痛点：**炒股没有体系，赚了不知道为什么，亏了也不知道错在哪**；大量历史交易难以总结规律，容易重复踩坑。

### 15.2 核心功能

复盘功能会逐笔分析用户的历史交易行为，结合交易时间的行情数据和新闻资讯生成完整的分析报告：

| 模块 | 内容 | 中长线价值 |
|------|------|-----------|
| **操作合理性评估** | 客观评价每笔交易的决策逻辑 | 识别冲动交易、追涨杀跌等行为偏差 |
| **潜在优化空间识别** | 指出交易中的可改进点 | 如"某笔交易未设止盈导致盈利回吐30%" |
| **后续观察重点提示** | 给出针对性的交易改进建议 | 形成可执行的改进计划 |
| **高光操作标记** | 标记成功的交易操作 | 强化正确的交易行为模式 |
| **待改进行为标记** | 标记需要改进的操作 | 避免重复踩坑 |

### 15.3 复盘触发方式

- 在持股列表中**长按任意个股**即可触发该股的持仓复盘
- 通过任务助手对话触发："帮我复盘今天的交易"
- 盘后自动推送当日复盘摘要

### 15.4 技术实现

```
交易复盘
├── 数据层: 用户历史交易数据 + 交易时间行情数据 + 同期新闻资讯
├── 分析层: AI 逐笔交易行为分析 + 决策逻辑评估
├── 标记层: 高光操作 + 待改进行为双标记
├── 建议层: 方向性优化分析 + 投教内容推荐
└── 合规层: 基于历史数据分析，不构成未来交易建议
```

## 十六、智能交易页面（网格交易 + 分批止盈 + AI 条件单）

> 智能交易工具是中长线投资者执行纪律化交易的利器，核心价值是**用规则替代情绪**，避免人为操作中的追涨杀跌和贪婪恐惧。

### 16.1 网格交易

**中长线场景：** 震荡市中自动低买高卖，摊薄持仓成本，不浪费持仓时间。

| 功能 | 说明 | 中长线价值 |
|------|------|-----------|
| 自动低买高卖 | AI 自动在预设价位区间内分档买卖 | 持仓等待期间也能赚价差 |
| AI 参数助手 | 自动回测近 1 年历史行情，生成更优交易参数 | 解决"不会设参数"的痛点 |
| 成交驱动网格 | 上一笔全部成交后才执行下一轮委托 | 过滤假突破，减少无效交易 |
| 档位可视化 | 网格档位和委托状态可视化展示 | 一目了然掌握策略执行状态 |

**AI 参数助手流程：**
```
选择标的 → 输入可用资金和风险偏好（保守/稳健/进取）
    │
    ▼
AI 自动回测近 1 年行情 → 计算更优参数
    │
    ├── 更佳涨跌幅间距
    ├── 初始基准价
    ├── 每笔委托数量
    └── 最大持仓上限
    │
    ▼
一键复制 AI 参数 / 自行微调 → 确认部署
```

### 16.2 分批止盈

**中长线场景：** 持仓上涨后分批卖出，既不错过后续涨幅，也不坐过山车。

| 功能 | 说明 | 中长线价值 |
|------|------|-----------|
| 分批卖出 | 按比例分批止盈，如涨 5% 卖 30%、涨 10% 卖 50% | 科学规划卖出节奏，让利润落袋更稳 |
| AI 回测参考 | AI 扫描行情特征，提供智能分档方案 + 历史回测数据 | 不凭感觉设参数，有数据支撑 |
| 规则化执行 | 到价自动触发，规则化执行避免情绪干扰 | 解决"舍不得卖"的心理困境 |
| 剩余仓位持有 | 部分仓位继续持有博取更高收益 | 平衡"卖飞"和"回吐"的矛盾 |

### 16.3 AI 条件单

AI 条件单是传统条件单的 AI 增强版，覆盖网格交易、分批止盈、止盈止损等多种策略：

| 功能 | 传统条件单 | AI 条件单 |
|------|----------|----------|
| 参数设置 | 手动调参，凭感觉拍板 | AI 自动回测生成更优参数 |
| 网格触发 | 到价即触发，容易被假突破诱骗 | 成交驱动，过滤假突破 |
| 止盈设置 | 全仓卖出或固定比例 | AI 智能分档 + 回测验证 |
| 操作方式 | 翻菜单、输数字 | 语音条件单，一句话搞定 |
| 运行方式 | 需 App 在线 | 云端 7×24 小时运行，断网也能触发 |

## 十七、热点捕手页面

> **热点捕手**是 AI 涨乐 AI 选股体系中的核心模块，通过跨模态 AI 热点中枢实时捕捉全网热点，帮助中长线投资者发现主题性投资机会。

### 17.1 页面定位

面向中长线投资者的热点捕手，核心价值不是追涨杀跌，而是**通过知识图谱理解热点的行业逻辑和产业链脉络**，找到真正有中长期价值的投资标的。

### 17.2 核心功能

| 功能 | 说明 | 中长线价值 |
|------|------|-----------|
| 跨模态 AI 热点中枢 | 实时扫描全网新闻、舆情、公告，捕捉市场热点 | 先人一步感知市场风向变化 |
| 热词云展示 | AI 提取热点关键词可视化 | 快速感知市场焦点和情绪 |
| 知识图谱关联 | 呈现"行业-个股"关联脉络 | 如"统一大市场→物流→兰剑智能"，理解产业链逻辑 |
| 华泰投研观点 | 整合"涨乐智见"投研脱敏观点 | 专业解读，避免"看热闹不看门道" |
| AI 认知多因子排序 | 六大技术指标 + 数百个因子排序 | 不是简单按涨幅排，而是 AI 综合评估潜力 |
| 动态风险防控中枢 | 实时剔除风险标的 | 避免踩雷，中长线安全第一 |
| 选股→盯盘联动 | 筛选出的标的可直接设置盯盘信号 | 发现机会 → 持续跟踪 → 条件触发 |

### 17.3 主题选股逻辑

```
热点事件发生
     │
     ▼
  AI 热点中枢识别事件主题
     │
     ▼
  知识图谱展开产业链脉络
     │
     ├── 上游：原材料/设备供应商
     ├── 中游：核心制造/服务商
     └── 下游：终端应用/渠道商
     │
     ▼
  AI 多因子排序筛选标的
     │
     ▼
  动态风险防控中枢剔除风险标的
     │
     ▼
  输出：主题投资标的列表 + 产业链图谱 + 华泰投研观点
```

## 十八、AI 研报精读页面

> **AI 研报精读**将数十页的专业研报提炼为几句核心要点，是中长线投资者高效获取专业投研信息的关键工具。

### 18.1 页面定位

痛点：**被铺天盖地的研报、快讯淹没，却抓不住重点**。一份深度研报动辄几十页，普通投资者难以高效提取核心观点。

AI 研报精读的解决方案：**AI 提炼研报核心，把复杂数据变成清晰解读，轻松吸收**。

### 18.2 核心功能

| 功能 | 说明 | 中长线价值 |
|------|------|-----------|
| 研报核心提炼 | 将几十页研报提炼为核心要点和关键数据 | 几分钟吸收专业分析师数周的研究成果 |
| 业绩预告解读 | 持仓股业绩预告 AI 提炼，用清晰逻辑说明数据变化和原因 | 不用自己翻公告，AI 帮你抓住重点 |
| 公告提炼 | 重大公告核心内容 AI 提取 | 把冗长公告变成几句话 |
| 研报与持仓关联 | 自动判断研报是否与用户持仓相关 | 只推送与你有关系的研报 |
| 对话式追问 | 对研报内容可以进一步追问 AI | 不懂的地方可以深入探讨 |

### 18.3 研报精读在产品中的触达点

AI 研报精读不是一个独立页面，而是**嵌入在多个功能模块中的基础能力**：

```
AI 研报精读触达点：

  早点听播报 ←── 研报提炼后播报核心要点
       │
  特别提醒 ←── 重大公告/研报发布时 AI 提炼推送
       │
  持仓陪伴 ←── 持仓股相关研报自动提炼
       │
  事件捕手 ←── 事件相关研报提取专业解读
       │
  AI 对话 ←── 用户主动询问个股时调用研报知识
       │
  动态估值 ←── 四维度分析基于研报数据和分析师预期
```

### 18.4 技术实现

```
AI 研报精读
├── 数据层: 华泰研究所研报库 + 实时公告 + 分析师一致预期
├── 模型层: 金融垂类大模型后训练（注入华泰私有知识库）
├── 提炼层: 核心观点提取 + 关键数据结构化 + 逻辑链梳理
├── 关联层: 用户持仓/自选 → 相关研报自动匹配
└── 交互层: 摘要展示 + 对话式追问
```
