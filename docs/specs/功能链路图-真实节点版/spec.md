## 1. 背景与问题

用户反馈两点：

1. 上一版时序图使用自造的“前端 / 主图 / 感知层 / 研究层 / 研判层 / 出口”六列参与者，没有真实节点 ID，看不出与设计图 v1.3 的关系；用户要求“每个功能涉及到的节点都各画一幅图，而不是局部，没涉及的不画”，以便在五张图里找到共同骨架。
2. 上一版部分“改后”描述与功能原本作用不符，需要回归代码核实后再写。

## 2. 事实基线（2026-11-22 已核对代码）

### 2.1 当前架构事实

- `aistock-agent-py`：`StateGraph`，`START → supervisor → intent_router`，路由到 10 个可路由 worker：`morning / stock / sector / event / wind_leader / broadcast / general / hot_burst / alert / trend_score`，执行后 `END`；另有 5 个仅调度 worker：`review / rhythm_master / midday / midday_broadcast / iterate`（见 `agents/registry.py`）。
- 一次对话只进一个 worker，不共享 evidence / judgment。
- 目标架构真源：`docs/智慧大脑-系统结构设计图.html` v1.3 的 `TARGET`（47 节点 / 62 边）；契约真源：`docs/智慧大脑-架构与研判契约.md` v0.5。

## 5. 实现方案

### 5.1 文件

- 重写：`docs/智慧大脑-功能对照与链路说明.html`
- 追加：`changelog-pending.md`
- 不修改任何业务代码。

### 5.2 HTML 结构

- 保留上一版的手机 mockup、步骤、delta 样式，修正文案。
- 新增 `.arch-graph` 容器：`<div class="arch-graph" data-graph="home"></div>`，由内联 JS 生成 SVG。
- 新增 `.verify` 代码核实框、`.matrix` 矩阵表、`.node-dict` 折叠字典、`.caveat` 缺口说明。
- 页面最大宽度 1400px；SVG `viewBox="0 0 1420 568"`，容器横向可滚动，最小宽度 1120px。

### 5.3 SVG 渲染器（内联 JS）

- `LANES`：7 条泳道固定 x / w / 名称 / 颜色。
- `NODE`：节点字典（lane、标题、职责）。
- `ORDER`：每个泳道内的固定顺序（GT: T1,T2,T3,T4,O1；GR: R1,R2,R3,R5,R4,R6 等）。
- `SPECS`：5 个功能的 `nodes` / `edges` / `tool` / `note`。
- `renderGraph(container, spec)`：
  1. 画泳道背景、标题、GM 带、GX 带。
  2. 按 `ORDER` 计算节点坐标（y = 54 + index × 62，h = 52）。
  3. 画边（主链路 / 研究联动 / 校准 / 记忆读写）。
  4. 画节点（白底、左侧泳道色条、右上记忆徽标）。
  5. 画 GO 缺口框（仅选股）。
- 边类型：`main`、`orth`（J4→E1/E2/E3）、`side-up`、`side-down`、`side-bi`、`jump`、`cal`、`mem`、`memread`、`memlong`。
- 箭头 marker 在页面顶部隐藏 SVG 中定义一次：`mk-blue`、`mk-teal`、`mk-violet`、`mk-gray`。

## 7. 风险与取舍

- 47 个节点全部画进每张图会变成线团，因此每张图只画本功能子集；统一性靠固定泳道 / M 槽 / 图例保证，而不是重复画全图。
- 记忆读写采用“泳道 ↔ M 框”+ 节点徽标的压缩表示，不逐节点画 20 条交叉线；节点徽标仍能精确到具体节点。
- 选股出口缺失是目标图问题，不在本次文档里虚构节点；用虚线缺口框标注。
- 提醒页是站内列表，不等同于 E3 推送；文档必须区分“页面读账本”和“E3 推变化”。
