## 1.1 我在自审中发现并已修复的问题（3 个 P0）

| # | 问题 | 后果 | 修复 |
| --- | --- | --- | --- |
| **A-1** | **局永不结束 → 用户被永久锁死** | `uq_arena_runs_one_active` 只允许一个 `active` 局。若用户 5 天后不再登录、结算任务又出错，该局永远停在 `active`，**这个用户以后再也不能开新局** | 新增 `day_index` 字段；`status` 增加 `expired`；结算 cron 每日检查，`day_index > total_days` 时**强制局末结算**（用最后一次 NAV），失败则置 `expired` 释放唯一索引 |
| **A-2** | **局内池子没有落快照** | 只存了 `batch_id`。若上游 `ai_stock_selection_results` 被清理或改写，本局的池子、理由、排序全部不可复现——战报和反哺结论都失去依据 | 新增 `arena_run_pool` 表，开局时把池子（symbol / name / rank / reason / source_feature）**复制一份**进本局 |
| **A-3** | **卖出成本口径未定义** | `positions.avg_cost` 与 `attribution.realized_pnl` 可能基于不同成本，导致持仓页与战报的盈亏数字**对不上**，直接违反"同一数字在不同页面必须同值" | 统一为 **FIFO（先进先出）**：`positions.avg_cost` = 剩余批次加权成本；卖出按 FIFO 匹配批次计算已实现盈亏 |

## 1.4 评审会要回答的 6 个判断题

1. 是否认可 **"订单表即成交表"**（本期不做部分成交，不单设 trades 表）？
2. 是否认可 **FIFO 作为唯一成本口径**（不用移动加权平均）？
3. 是否认可 **"局内池子快照"独立成表**（而不是只存 batch_id）？
4. 是否接受 **超时强制结算**（第 6 个交易日仍未结算 → 自动局末结算）？
5. 是否接受 **不建跨域物理外键**，改应用层校验？
6. JSONB 字段（`fields_spec` / `props` / `fact_layer` / `evidence`）的 **schema 治理方式**由谁负责？

## 3.2 建议的条件表达格式（供讨论）

建议用一个轻量 DSL，让"流派 = 一组信号条件 + 权重 + 约束"：

```json
{
  "id": "institution_flow",
  "signals": [
    { "dim": "institution",  "op": "resonance",      "gte": 2,   "weight": 0.40 },
    { "dim": "capitalFlow",  "op": "netInflowDays",  "gte": 2,   "weight": 0.30 },
    { "dim": "trend",        "op": "score",          "gte": 70,  "weight": 0.20 },

  ],
  "constraints": { "maxPerIndustry": 3, "topN": 10 },
  "promptVersion": "ai-stock-selection.v1"
}
```

好处：可校验、可回算、可被 agent 生成、可被后台编辑。

## 3.6 口径修正结论（8 条已定）

原"需算法侧回答"的 5 个问题已由我方直接定口径，结果写入 PRD **技术附录 F.7**：

| # | 原问题 | 结论 |
| --- | --- | --- |
| 1 | 成交额单位差 10 倍 | 以注释为准：80000 / 50000（即 8000 万 / 5000 万） |
| 2 | 最终排序不是 weight | **rank 由代码按 weight 降序赋值**，LLM 只决定入选与理由 |
| 3 | 机构窗口口径不一 | 统一按**交易日 3 天** |
| 4 | `min_resonance=4` 被压到 3 | **就用三源**，合法范围统一 `[2,3]` |
| 5 | 盈利预测靠正则、无机构数下限 | 补正则（万元/下降）+ 加**机构数 ≥3** 过滤 |
| 6 | 趋势评分有 LLM 注入通道 | 移除模块级隐式状态，改**显式入参** |
| 7 | ma60 用不复权价 | **统一用前复权** |
| 8 | 没有配置快照 | `runs` 增加 `config_snapshot JSONB` |
