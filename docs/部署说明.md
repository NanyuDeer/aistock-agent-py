  重启一下API服务

## 第二步：部署 QQ 机器人

1. 在env里面补充
```env
QQ_ENABLE=true
QQ_GROUP_ID=916687897
QQ_HISTORY_DAYS=3
QQ_FILE_POLL_INTERVAL=900
```

2. 构建启动

```bash
docker compose --env-file .env -f deploy/qq/docker-compose.yml up -d --build
```

这里要用 `--build`，安装 Tesseract 和 `chi_sim` 中文 OCR 依赖。

第三步：配置 NapCat

1. 日志里应该会打印二维码，拍照给我，我拿 QQ 小号扫码登录。或者浏览器打开 http://<服务器IP>:6099/webui/ ，NapCat 面板上会有二维码区域。

2. 在 NapCat WebUI 配置 OneBot 反向 WebSocket：（客户端）

```text
ws://feishu-bot:8081
```

3. 开启心跳。
4. 不要删除 `napcat_data` 和 `bot_data`：前者保存登录态，后者保存下载文件和去重状态。
